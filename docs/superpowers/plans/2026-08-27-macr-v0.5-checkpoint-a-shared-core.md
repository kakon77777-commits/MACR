# MACR v0.5 Checkpoint A Shared-Core Corrections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a reviewable MACR v0.5a1 shared-core checkpoint with cross-process-safe event storage and admission, authorization provenance, pre-validation provider observations, immutable candidate capture, exact return-contract enforcement, deterministic contradiction preflight, complete cost accounting, and preservation-first legacy migration.

**Architecture:** Keep v0.4 provider adapters and `TaskContract` callable while introducing typed execution observations around them. Route runtime events, leases, authority, and accounting through transactional SQLite stores on the configured D-drive state root; preserve the legacy JSONL byte-for-byte and import it through an explicit quarantine-aware migration. Compile worker instructions from structured return contracts, capture raw answer bytes before validation, and keep provider completion, contract validity, materialization, verification, and acceptance independent.

**Tech Stack:** Python 3.11+, standard-library `sqlite3`, `unittest`, `multiprocessing`/`subprocess`, PowerShell 5.1+, SHA-256, JSON, existing MACR provider transports.

**Spec:** `docs/superpowers/specs/2026-08-27-macr-v0.5-direct-chat-design.md`
