# MACR v0.6 Dynamic Coordination Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. This project uses inline implementation; implementation subagents are not authorized. One twin verification seat may be used only when the operator explicitly authorizes it. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, evidence-backed MACR control plane that observes model markets, qualifies exact model-route-role combinations, compiles shadow-first coordination plans, and executes only explicitly authorized verified topologies.

**Architecture:** Add a dedicated observatory/planning database and focused modules beside the v0.5 runtime. External model data enters an untrusted snapshot boundary; append-only evidence drives rebuildable Passport projections and route-specific qualifications. A deterministic planner applies hard eligibility before lexicographic ranking, emits canonical plan digests, and reaches provider execution only through existing authority, lease, candidate-vault, verification, and accounting paths.

**Tech Stack:** Python 3.11+, standard library dataclasses/enums/protocols, SQLite WAL with `synchronous=FULL`, `unittest`, PowerShell entry points, existing MACR provider/runtime abstractions.

**Spec:** `docs/superpowers/specs/2026-08-28-macr-v0.6-dynamic-coordination-design.md`

```python
def canonical_json_bytes(value: object) -> bytes:
    try:
        text = json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False)
    except (TypeError, ValueError) as exc:
        raise ValueError("canonical data must be finite JSON") from exc
    return text.encode("utf-8")

def sha256_id(namespace: str, value: object) -> str:
    if not namespace or not namespace.isascii():
        raise ValueError("namespace must be non-empty ASCII")
    return hashlib.sha256(namespace.encode("ascii") + b"\0" + canonical_json_bytes(value)).hexdigest()
```
